# Homebz — تطبيق Expo

التصميم الأصلي (`web/Homebz.html`) يشتغل داخل التطبيق بدون أي تعديل على التصميم.

## التشغيل على Expo Go

```bash
cd homebz-app
npm install
npx expo start
```

امسح رمز QR بتطبيق **Expo Go** (أندرويد) أو بالكاميرا (آيفون).
إذا الجوال والكمبيوتر مو على نفس الشبكة: `npx expo start --tunnel`

## تعديل التصميم

عدّل `web/Homebz.html` وبعدها شغّل `npm run build:html` (ويتم تلقائياً مع `npm start`).

## الإضافات

- يملأ الشاشة كاملة، وألوان شريط الحالة والحواف تتغير مع كل شاشة.
- الخطوط (Tajawal و Manrope) مدمجة في التطبيق وتشتغل بدون إنترنت.
- زر الرجوع في أندرويد يقفل الصفحة أو النافذة المفتوحة، ويرجع للرئيسية، وبعدها يطلع من التطبيق.
- واتساب وخرائط قوقل والروابط الخارجية تنفتح في تطبيقاتها.
- اهتزاز خفيف (Haptics) عند اللمس والتنبيهات.
- التطبيق يتذكر اللغة اللي اخترتها.
- رفع الصور (الشعار والمنتجات) شغّال من معرض الصور.
- أيقونة التطبيق وشاشة البداية مأخوذة من شعار Homebz.
- إذا انهارت صفحة التطبيق يعيد تحميلها تلقائياً.
